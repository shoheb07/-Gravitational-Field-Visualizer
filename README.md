# -Gravitational-Field-Visualizer
The Gravitational Field Visualizer is a physics simulation that displays the gravitational field generated by one or more masses. The field is represented using vectors that show the direction and relative strength of gravitational attraction.

Gravitational Field Visualizer

Overview

Gravitational Field Visualizer is a scientific simulation project developed using Python, Pygame, and NumPy. The application visualizes gravitational fields generated by massive objects and displays the resulting vector field in real time.

The project helps students understand how gravity acts at different points in space and how multiple masses combine to create complex gravitational interactions.
